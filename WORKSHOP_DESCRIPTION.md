## 简体中文

我是叮咚。玩 RimWorld 时，我想保留爵位、荣誉、许可、灵能与授勋，却不想让头衔强制要求豪华生活。我找过现有 Mod，没有找到足够贴近这一需求的方案，于是提出 Honor, Not Luxury（荣誉贵族）的想法，先为自己的存档制作，现在公开给有同样需求的玩家使用。

在 Mod 设置中，卧室、日常谒见厅、贵族服装款式、服装品质、食物、爵位最低期望和可选的工作限制，都可以分别选择：保持原有机制／仅正式殖民者免除／所有角色免除。默认免除正式殖民者的前六项，工作限制保持原有机制。授勋仪式本身的谒见厅验收仍然保留。

需要 Royalty DLC 和 Harmony。OA 金鸢尾兰并非必需；其使用原版贵族需求机制的头衔适用同一规则。可以中途加入。2.0 不把豁免写进角色存档，停用并重启后原规则重新参与判定；曾用 1.x 原型保存过的存档可能有旧版遗留字段，请见 README。

需求、功能取舍和适用范围由我提出并决定；**代码由 AI 编写，我负责审阅、游戏内测试和维护**。我在自己的 140+ Mod 环境中验证了加载、设置与多项要求切换，切回原机制后相应心情减益会重新出现；未观察到由本 Mod 引起的新增报错。其他 Mod 组合未获全面保证。我会以个人游玩环境为基础继续维护。兼容问题请在 GitHub Issues 报告，并附版本、Mod 列表、设置、复现步骤和日志。欢迎改进、Fork 或制作 Continued；原创源码和文档采用 MIT 许可证。

## English

I'm DingDong. I wanted to keep royal titles, honor, permits, psycasts, and bestowing without making my colonists live in luxury. I looked for an existing mod close enough to that idea and did not find one, so I made Honor, Not Luxury for my own colony and am sharing it with players who want the same choice.

Bedroom, daily throne room, apparel style, apparel quality, food, minimum expectation, and optional work restrictions each have three scopes: Unchanged / Exempt permanent colonists / Exempt everyone. The first six default to permanent colonists; work restrictions remain unchanged. Throne-room requirements for bestowing ceremonies are preserved.

Requires Royalty and Harmony. Oberonia Aurea is optional; its titles that use vanilla royal requirement paths follow the same settings. You can add version 2.0 to an existing save. It does not persist exemptions on pawns, so disabling the mod and restarting allows the original rules to apply again. Saves written with the old 1.x prototype may contain legacy changes; see the README.

The idea, feature choices, and scope are mine; **AI wrote the mod's code, and I reviewed and tested it**. In my 140+ mod setup I verified loading, settings, independent requirement switches, and the return of mood penalties when a rule is set to Unchanged. I have not observed new errors attributable to this mod there. Universal compatibility is not guaranteed. I intend to maintain it around my personal play setup. Please report reproducible compatibility issues with versions, mod list, settings, steps, and logs.
