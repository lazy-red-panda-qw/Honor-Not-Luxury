# Honor, Not Luxury（荣誉贵族）

[English](README.en.md)

让贵族头衔代表荣誉，而不必强制过上奢侈生活。

本 Mod 可以分别调整爵位带来的卧室、日常谒见厅、服装款式、服装品质、食物、最低期望和工作限制。每项可选择保持原有机制、仅正式殖民者免除或所有角色免除。默认豁免正式殖民者的前六项，工作限制保持原有机制；访客等非殖民地角色默认保留原规则。

爵位、荣誉、许可、灵能等权益保留，**授勋仪式的谒见厅要求也保留**。需要 **RimWorld 1.6、Royalty DLC 和 Harmony**，支持简体中文与英语。各项范围可在游戏的 Mod 设置中调整，支持已有存档中途加入和停用。

我是叮咚。这个 Mod 源于我的个人游玩需求：我没有找到足够贴近这一想法的现有 Mod，于是提出需求，**由 AI 编写代码，我负责审阅和游戏内测试**。公开是为了方便有同样需求的玩家。
