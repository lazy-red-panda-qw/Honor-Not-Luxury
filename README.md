# Honor, Not Luxury（荣誉贵族）

我是叮咚。玩 RimWorld 时，我想保留贵族头衔带来的身份与权益，却不想让头衔强制要求奢侈生活。我找过现有 Mod，没有找到足够贴近这一需求的方案，于是提出了 Honor, Not Luxury 的想法，先为自己的存档制作，现在把它分享给有同样需求的玩家。

**需求、功能取舍和适用范围由我提出并决定；Mod 代码由 AI 编写，我负责审阅、游戏内测试和维护。**

这个 Mod 支持分别调整爵位的卧室、日常谒见厅、服装款式与品质、食物、最低期望及工作限制，并可选择只豁免正式殖民者或所有角色。授勋仪式的谒见厅验收保留。需要 RimWorld 1.6、Royalty DLC 和 Harmony。
